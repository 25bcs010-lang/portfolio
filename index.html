How I Think

Deconstruct first.

Build the mental model.

Then execute precisely.

Reasoning before code.
Every. Single. Time.

Every system I build begins with a single question I refuse to skip: what is the actual problem here? Not the surface symptom — the root cause. I deconstruct requirements into their smallest logical units, trace every dependency, and construct a complete mental model before writing a single line of code. This is not slowness. This is the discipline that makes the build phase fast and the shipped product correct. I fine-tune AI agents locally because I want to understand the weights, not just call an API. I work at the GPU level because I want to understand the parallelism, not just abstract it away. Understanding the machine — all the way down — is how I build systems that keep working when the abstractions break.
